My professionally-oriented website is a portfolio site for John Kim, a senior studying mathematics at NYU. The site presents my academic background, problem-solving interests, and growing web design skills in a format that can be useful after this class is over. The website is organized into three pages: a homepage, a selected work page, and a contact page. The homepage introduces me and explains the main focus areas of the portfolio, including mathematical thinking, web design, and creative problem solving. The work page presents sample project directions using a clean card-based layout and includes a short audio element as a process note. The contact page gives visitors a way to learn about my availability and send a project inquiry. The design uses consistent navigation, readable headings, semantic sections, images with descriptive alternative text, and responsive layouts that change from one column on mobile screens to multiple columns on larger screens.
